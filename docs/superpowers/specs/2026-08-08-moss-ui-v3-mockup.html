优化点清单（编号对应界面标注）

  1. 模式切换改分段控件："操作员 ▾"下拉式 → 分段开关 + 工程师 🔒 暗示权限门槛，状态一目了然且不易误点。
  2. 顶部统计折叠：A/B/C/D+纠错+不合格 6 组数字常驻 → 单 chip"今日 N 盘 · 通过率"，明细收进 popover；"通过率"与前后文字留足间隔。
  3. 品级描述词 + 品级色加深：横幅大字旁标注良好 / 中等 / 较差 / 不合格（A/B/C/D 均为正常品级，不用动作指令）；品级色下沉至 700 深度，白字对比度全部 ≥ 4.8:1（原 3.1–3.3:1，横幅上 10–16px 小字不达 AA）。
  4. 正方形画面铺满：相机画面为正方形，取景区域按高=宽设定、图像 slice 铺满整个区域，左右深色画框自然延伸，不再出现缩放留白。
  5. 选中态改中性色：浅橙底 + 橙边框 → 中性 slate 底 + 品级色左条。橙色在设计系统里属于 C 品级/警告语义，选中态用它违反正交原则。
  6. 底栏主次与防误触：开始运行（主）放大加深、运行时禁用；停止运行与开始之间加分隔线拉开物理距离；连接相机降为 ghost 并显示连接状态。
  7. 工程师参数栏：分组小标题 11px 大写间距、表单行 30px 统一控件高、操作按钮纵向排列于栏底，底部常驻吞吐统计（平均耗时/超时/质量异常）。
  8. 条件显示软件间隔：仅触发模式 = 软件连续时显示"软件间隔"行，其余模式隐藏，参数栏不堆无用项。
  9. 复检语义修正：⚠ 需复检仅由"置信度低于阈值"触发，与品级无关（C/D 品级本身不自动复检）。
  10. 质量不合格措辞修正：拒采 · 未出品级 → "图像质量不合格 · 过曝 · 原图已入库"——此类记录同样入库存档；chip 用"质量异常"与品级 D「不合格」区分。
  11. 字号下限 11px：时间 9px / 组标题 9px / 角标 8px → 全部 ≥ 10.5px，产线 1m+ 视距可读；Emoji 图标统一改 SVG。
  12. 实现层修复：历史列表拒采原因未翻译（rejected_blur 原文显示）、置信度进度条/等待 spinner 缺失、Toast × 在卡片底部、按钮无禁用状态机——详见评审文档 §2。
